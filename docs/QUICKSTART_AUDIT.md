# 🚀 Быстрый Старт: Как Протестировать Скрипт Аудита

## 📋 Минимальный Чек-лист

### 1. Подготовка (5 минут)

```powershell
# Откройте PowerShell в папке проекта
cd d:\Projects\Project_5

# Установите зависимости
pip install requests pandas openpyxl urllib3

# Создайте папку для данных
mkdir data
```

### 2. Подготовьте Тестовый Файл Excel

Создайте файл `data\test_sites.xlsx` с колонками:

| Name | Website | Rating |
|------|---------|--------|
| Test Site 1 | example.com | 4.5 |
| Test Site 2 | google.com | 5.0 |
| Test Site 3 | bbc.com | 4.8 |

**Или используйте любой существующий Excel файл с колонкой `Website` или `URL`**

### 3. Запустите Тест (10 сайтов)

```powershell
python scripts\audit_websites.py data\test_sites.xlsx data\result_test.xlsx --limit 10
```

### 4. Откройте Результат

```powershell
# Автоматически откроется Excel
start data\result_test.xlsx
```

**Что вы увидите:**
- 🟢 Зелёные ячейки = всё хорошо
- 🟡 Жёлтые = есть проблемы
- 🔴 Красные = критично
- Колонка **🎯 Lead Quality** покажет качество лида

### 5. Проверьте Результат Вручную

**Выберите 2-3 сайта из списка и откройте их в браузере:**

1. **HTTPS проверка:** Посмотрите на адресную строку — есть замочек? ✅
2. **Mobile проверка:** Уменьшите размер окна браузера — текст адаптируется? ✅
3. **Скорость:** Сайт быстро загрузился? (<2 сек = 🟢 Fast)

## 📊 Интерпретация Результатов

### Lead Quality (Колонка 🎯)

| Значение | Что это значит | Действие |
|----------|---------------|----------|
| **🔥 HOT LEAD** | Критическая проблема + хороший бизнес (rating ≥4.0) | **ТОП приоритет для продажи!** |
| **🟠 QUALIFIED** | Есть проблемы (HTTP, no mobile, outdated) | Хороший кандидат для pitch |
| **🟡 POTENTIAL** | Небольшие проблемы (медленно, старый дизайн) | Можно использовать для upsell |
| **⚪ SKIP** | Всё работает отлично | Пропустить |

### Колонки Аудита

| Колонка | 🟢 Хорошо | 🔴 Проблема |
|---------|----------|------------|
| **🌐 Website Status** | ✅ Online | ❌ Offline |
| **🔒 Security** | ✅ HTTPS + SSL | ❌ HTTP Only |
| **⚡ Speed** | 🟢 Fast (<1s) | 🔴 Slow (>3s) |
| **📱 Mobile** | ✅ Yes | ❌ No |
| **🎨 Design** | ✅ Modern | ⚠️ Outdated |

## ❓ Частые Вопросы

**Q: Скрипт требует API ключ PageSpeed?**  
A: Нет! Замер скорости делается без API (реальное время загрузки). PageSpeed опционален.

**Q: Сколько времени занимает проверка?**  
A: ~8-10 секунд на сайт (включая паузы для безопасности)

**Q: Можно ли запустить на CSV файле?**  
A: Да! Скрипт автоматически распознаёт формат:
```powershell
python scripts\audit_websites.py data\sites.csv data\result.csv
```

**Q: Что если моя колонка с URL называется "homepage"?**  
A: Переименуйте в `Website` или `URL` в Excel перед запуском
