## 🎯 Что Делает Скрипт

Скрипт `audit_websites.py` автоматически проверяет сайты из вашего Excel/CSV файла и выявляет технические проблемы, которые могут отпугивать клиентов и снижать продажи бизнеса.

### Проверяемые Параметры

| № | Название | Что проверяется | Зачем это важно |
|---|----------|----------------|----------------|
| 1 | **🔒 HTTPS/SSL** | Использует ли сайт безопасное соединение | Клиенты видят "НЕ БЕЗОПАСНО", Google понижает в поиске |
| 2 | **🌐 Доступность** | Открывается ли сайт (200 OK) | Если сайт не работает — бизнес теряет деньги |
| 3 | **⚡ Скорость** | Время загрузки (секунды) | 53% пользователей уходят если сайт грузится >3 сек |
| 4 | **📱 Мобильная версия** | Есть ли viewport tag | 60% пользователей с телефонов |
| 5 | **🎨 Дизайн** | Устаревшие технологии (Flash, jQuery 1.x) | Плохой дизайн = "компания не развивается" |

## 🔧 Как Работает Скрипт (Пошагово)

### Шаг 1: Загрузка Данных

```python
df = pd.read_excel('dentists.xlsx')  # Читает Excel/CSV
```

Скрипт автоматически находит колонку с URL:
- Ищет точное совпадение: `Website`, `URL`, `Site`
- Если не находит — ищет частичное: `website_url`, `site_link` и т.д.

**❗ Важно:** Если ваша колонка называется нестандартно (например, `homepage`), скрипт не найдет её. Переименуйте в `Website`.

---

### Шаг 2: Нормализация URL

```python
normalize_url("bostondental.com")
# → https://bostondental.com
```

Скрипт «исправляет» URL:
- Добавляет `https://` если его нет
- Убирает пробелы и лишние символы
- Проверяет валидность доменного имени

---

### Шаг 3: Проверка HTTPS и SSL

```python
# 1. Проверка HTTPS
is_https = url.startswith('https://')

# 2. Проверка SSL сертификата
ssl_valid = ssl.get_server_certificate((domain, 443))
```

**Результаты:**
- ✅ **HTTPS + SSL**: Всё отлично
- ⚠️ **HTTPS (SSL Error)**: Сертификат просрочен или невалиден
- ❌ **HTTP Only**: Критично! Сайт не защищён

---

### Шаг 4: Проверка Доступности и Скорости

```python
start_time = time.time()
response = requests.get(url, timeout=10)
load_time = time.time() - start_time

if response.status_code == 200:
    site_available = True
```

Скрипт замеряет **реальное время загрузки** (без API ключа PageSpeed):
- **🟢 Fast**: < 1 секунда
- **🟡 Average**: 1-3 секунды
- **🔴 Slow**: > 3 секунд

**Важно:** Замер делается с сервера, а не как у конечного пользователя. Реальная скорость может быть медленнее.

---

### Шаг 5: Проверка Мобильной Версии

```python
html = response.text
if 'viewport' in html.lower():
    is_mobile_friendly = True
```

Скрипт ищет мета-тег:
```html
<meta name="viewport" content="width=device-width">
```

**Точность:** ~95% для старых сайтов. Современные фреймворки (React, Next.js) всегда добавляют viewport.

---

### Шаг 6: Проверка Устаревшего Дизайна

Скрипт ищет в HTML коде признаки «старости»:

| Индикатор | Что это значит | Год технологии |
|-----------|---------------|----------------|
| Flash (`<embed`, `<object`) | Устаревшая анимация | 1996-2010 |
| jQuery 1.x | Старая библиотека | 2006-2013 |
| `<table>` для вёрстки | Табличная вёрстка | 1998-2005 |
| Нет viewport | Не адаптивный сайт | До 2010 |
| `<marquee>` | Бегущая строка | 90-е годы |
| `<frameset>` | Фреймы | 1996-2000 |

**Результат:**
- ✅ **Modern**: Признаков нет
- ⚠️ **Outdated**: Найдено 1+ проблем

### Шаг 7: Определение Качества Лида

```python
def determine_lead_quality(severity, rating):
    if severity == 'CRITICAL' and rating >= 4.0:
        return "🔥 HOT LEAD"  # Критическая проблема + хороший бизнес
    elif severity == 'CRITICAL':
        return "🟠 QUALIFIED"  # Критическая проблема
    elif severity in ['HIGH', 'MEDIUM']:
        return "🟡 POTENTIAL"  # Есть проблемы
    else:
        return "⚪ SKIP"  # Всё работает
```

**Логика:**

**🔥 HOT LEAD** (Горячий лид):
- Сайт **не работает** ИЛИ **HTTP** (критично!)
- Рейтинг бизнеса ≥ 4.0 → У него есть деньги, но сайт губит продажи

**🟠 QUALIFIED** (Квалифицированный):
- Критические проблемы, но низкий рейтинг
- Или проблемы с Mobile/Design/Speed

**🟡 POTENTIAL** (Потенциальный):
- Небольшие проблемы (медленная скорость, старый дизайн)

**⚪ SKIP** (Пропустить):
- Всё работает отлично

3. **Красивыми заголовками:**
   - Синий фон
   - Белый текст
   - Жирный шрифт

4. **Автофильтрами:**
   - Можно фильтровать по Lead Quality
   - Сортировать по Rating

## 🐛 Troubleshooting

### Проблема: "Module not found: openpyxl"

```powershell
pip install openpyxl
```

---

### Проблема: "No website column found"

**Причина:** Колонка с URL называется нестандартно

**Решение:**
1. Откройте Excel файл
2. Переименуйте колонку в `Website` или `URL`
3. Запустите снова

---

### Проблема: "SSL Error" для всех сайтов

**Причина:** Блокировка антивирусом/файрволом

**Решение:**
```python
# В коде скрипта уже есть:
requests.get(url, verify=False)  # Отключает проверку SSL
```

---

### Проблема: Скрипт "зависает"

**Причина:** Сайт не отвечает (timeout)

**Что происходит:**
- Скрипт ждёт 10 секунд
- Затем помечает сайт как "⏱️ Timeout"
- Продолжает работу

**Норма:** 1-2% сайтов могут быть недоступны

---

### Проблема: Результат не сохраняется

**Проверьте:**
```powershell
# Права на запись в папку
dir data\
# Можно записывать?
```

**Решение:** Закройте Excel файл если он открыт
